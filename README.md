# Shiralat Showcase v1.1

نسخه اصلاح‌شده و آماده Railway.

- مسیرهای templates و static به‌صورت صریح تنظیم شده‌اند.
- وجود قالب‌های ضروری هنگام شروع بررسی می‌شود.
- endpoint سلامت: `/health`
- ویترین فارسی و RTL، پنل مدیریت، دسته‌بندی، آپلود تصویر و صفحه محصول.

متغیرهای Railway: `ADMIN_USERNAME`, `ADMIN_PASSWORD`, `SECRET_KEY`

برای سایت واقعی حتماً نام کاربری و رمز پیش‌فرض `admin/admin123` را تغییر بده.
